フォトログ（オフライン対応版）公開と配布の手順

【中身】
  index.html       アプリ本体
  sw.js            オフライン用（部品を端末に保存する仕組み）
  manifest.json    ホーム画面用の設定
  icons/           アイコン
  vendor/          PDF作成と数字読み取りの部品（約11MB）

【1. GitHubで公開する（無料）】
  1) github.com で無料アカウントを作り、右上の「+」→「New repository」。
     名前は半角英数字（例: photolog）。「Public」を選んで作成。
  2) 作ったページの「uploading an existing file」を押し、
     このフォルダの中身（index.html, sw.js, manifest.json, icons, vendor）を
     すべてドラッグ＆ドロップ。「Commit changes」を押す。
     ※ パソコンのブラウザで行ってください。フォルダごと入れられます。
  3) 「Settings」→「Pages」→ Branch を「main」「/ (root)」にして Save。
  4) 数分後、次のURLで公開されます。
       https://（ユーザー名）.github.io/（リポジトリ名）/
     ※ このURLは変えないでください。変えると、各iPhoneの保存データが見えなくなります。

【2. 各iPhoneに入れる】
  1) 通信できる場所で、SafariでURLを開く。
  2) カメラと位置情報を「許可」する。
  3) 画面左上の表示が「✓ オフライン可」になるまで待つ（初回は1分ほどかかることがあります）。
  4) 共有ボタン →「ホーム画面に追加」。
  5) 以後はホーム画面のアイコンから起動します（圏外でも起動できます）。

【3. 毎日の使い方】
  1) 走行距離の数字を、白い枠に合わせて撮影。
  2) 読み取った数字を確認（違っていたら直す）→「保存」。
  3) PDFができたら「ファイルに保存」→「"ファイル"に保存」→ 同じ名前が出たら「置き換える」。
     ※ 「撮影後にPDF」のチェックを外すと、自動作成を止められます。

【4. アプリを更新するとき】
  index.html などを差し替えたら、sw.js の VERSION（'v1'）を 'v2' のように上げてください。
  各iPhoneは、通信できるときに自動で新しい版を取り込み、次の起動から反映されます。

【5. 注意】
  - 写真とデータは、各iPhoneの中にだけ保存されます。Safariのデータ消去や、アプリの削除で消えます。
    大切な写真は、その日のうちにPDFを「ファイル」に保存してください。
  - 圏外では、住所は取得できず、緯度経度だけが入ります。
  - 数字の自動読み取りは、間違うことがあります。必ず確認してから保存してください。
